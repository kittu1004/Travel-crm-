## 🔧 How to Push & Trigger Your Build on `kittu1004/Travel-crm-`

1. In Google AI Studio, open the **Settings / Export** menu and select **Push to GitHub** (targeting `kittu1004/Travel-crm-`).
2. Every push to `main` or `master` (or any published release) automatically triggers `.github/workflows/build-debug-apk.yml`.
3. You can also trigger a build manually anytime by visiting **[Actions → Build & Release Debug APK](https://github.com/kittu1004/Travel-crm-/actions/workflows/build-debug-apk.yml)** and clicking **Run workflow**.
4. When the workflow completes (~2–3 minutes), tap the direct download link above on your Android phone to install **FleetCRM**.
