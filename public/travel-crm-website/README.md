# FleetCRM — Complete Travel CRM Website (Single Folder Package)

All files for the standalone **Travel CRM Website** are contained in this single folder (`travel-crm-website/`):

1. `index.html` — Main HTML5 entry point (Mobile Number + Password Login/Registration, Sidebar Navigation, Command Center Dashboard, History Views, and Modal Forms).
2. `styles.css` — Complete stylesheet featuring the Royal-Blue, Cyan & Violet-Purple wave headers, lavender-ice-blue gradient canvas, white `18px` cards, `#ECF3FF` icy-blue summary boxes, white primary header action buttons with royal-blue text, and **all-bold typography**.
3. `app.js` — Complete client-side Travel CRM application engine (Mobile Number + Password authentication with zero email prompts, Bookings, Invoices PDF print/export, GST Tax ledger, Vehicles & Documents, Vehicle Maintenance with *Next Service Note* at the end of the form, Driver Roster, Trip Expenses, Customer Data, Reports & Export, and System Settings).

## How to Run
- Double-click `index.html` in any desktop or mobile browser, or host this folder directly on GitHub Pages, Firebase Hosting, Netlify, or Vercel.
